# vlsi-physical-design-openlane
RTL to GDSII Physical Design flow using Openlane and Sky130 pdk
## Project Overview
This project implements SPM (Serial Peripheral Master) design using OpenLane RTL-to-GDSII flow on Sky130 130nm PDK.

## Tools Used
- OpenLane
- Sky130 PDK
- Magic VLSI
- PrimeTime STA

## Flow Steps Completed
- Synthesis
- Floorplanning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- DRC/LVS
- Timing Closure
